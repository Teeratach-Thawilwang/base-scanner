# การเขียนไฟล์ markdown

โหลดทุกครั้งที่อ่านหรือเขียนไฟล์ `.md` รวม plan และไฟล์ใต้ `.claude`
กฎในนี้กำหนดรูปร่างของทั้งหน้า กฎการเขียนของ output style ที่เปิดอยู่ยังคุม
ทุกประโยคบนหน้านั้นต่อ

## โครงไฟล์

- **เปิดด้วย `# <ชื่อไฟล์>` บรรทัดเดียว แล้วบรรทัดถัดไปเป็นหัวข้อแรกเลย**
  ไม่มี blockquote ไม่มีการ์ดสรุป ไม่มี list บอกว่าไฟล์นี้ครอบคลุมอะไร
  ไม่มี status line สิ่งที่ควรพูดตรงนั้นเป็นของหัวข้อที่มันอยู่
- **หัวข้อใช้ `##` กับ `###` เท่านั้น ห้ามลึกกว่านั้น และห้ามใช้ `#` ซ้ำ**
  การซ้อนลึกทำให้ผู้อ่านต้องจำว่าตอนนี้อยู่ระดับไหน
  อยากได้หัวข้อย่อยคือเขียนสองหัวข้อวางเคียงกัน แต่ละหัวข้อมีชื่อของตัวเอง
- **หัวข้อเป็นวลีนามสั้น ตั้งชื่อตามเนื้อหาของตัวเอง**
  ตัวเล็กทั้งหมด ยกเว้นชื่ออังกฤษที่ code สะกดแบบนั้น: `FLAG_SECURE`, CEFR
- **ห้ามเลขหน้า heading ห้าม `<a id>` ห้ามอ้าง "ดูข้อ 7"**
  แทรกหัวข้อหนึ่งเข้าไป เลขข้างหลังทุกตัวกลายเป็นเท็จ pointer ทุกอันผิดตาม
  อ้างไฟล์อื่นใช้ลิงก์ อ้างในไฟล์เดียวกันพูดประโยคที่ผู้อ่านต้องการซ้ำ
- **เนื้อหาอยู่บรรทัดถัดจากหัวข้อเสมอ** ไม่เขียนต่อท้ายบรรทัดเดียวกับหัวข้อ

## ย่อหน้าและ bullet

- **หนึ่งย่อหน้าหนึ่งประเด็น** สองประเด็นไม่แชร์ย่อหน้าเดียวกัน
- **หนึ่ง bullet หนึ่งประเด็น ตัวหนาคือประเด็น บรรทัดใต้มันคือรายละเอียด**
  ตัวหนาใช้เป็นประเด็นนำของ bullet เท่านั้น ไม่ใช้เน้นกลางประโยค
  ห้ามตัวเอียงทั้งไฟล์ ห้ามใช้ `·`
- **หลายรายการชนิดเดียวกันเขียนเป็น list หนึ่งรายการต่อบรรทัด**
  ห้ามยัดรวมในประโยคเดียว รายการเดียวไม่นับเป็น list ให้เขียนเป็นประโยค
- **ตัดบรรทัดที่ 80 คอลัมน์** บรรทัดต่อของ bullet เยื้องตรงกับข้อความของมัน
- **ห้าม `—` ทั้งขยายประเด็นและแยกประเด็น** เขียนประโยคใหม่เป็นภาษาพูดแทน
- **ห้าม `§`** เหมือนการอ้างอิง แต่คลิกแล้วไม่ไปไหน
- **ในประโยค `,` เป็นตัวคั่นรายการอย่างเดียว** ตั้งแต่สามรายการขึ้นไปอยู่ใน list

## ภาษา

- **ร้อยเรียงด้วยถ้อยคำไทย ไม่แปลประโยคต่อประโยคจากอังกฤษ**
  ต้นฉบับเป็นอังกฤษก็ตาม เอาความหมายมาเขียนใหม่
  สำนวนที่คนไทยไม่พูดตัดทิ้ง พูดความหมายตรง ๆ แทน
  ❌ ตัวยาของปัญหานี้คือ cache
  ✅ ที่เขาบอกว่าแก้ได้คือ cache
- **หนึ่งสิ่งใช้ชื่อเดียวทุกครั้ง ห้ามเปลี่ยนคำกลัวซ้ำ**
  เปลี่ยนคำแล้วผู้อ่านต้องเดาว่าใช่สิ่งเดียวกันไหม
- **กริยาอยู่เป็นกริยา ห้ามทำเป็นนามแล้วใช้กริยาอื่นประกอบ**
  ❌ ผมทำการตรวจสอบ config ก่อน แล้วจึงดำเนินการแก้ไข
  ✅ ผมตรวจ config ก่อน แล้วแก้
- **ประธานของประโยคคือผู้กระทำ ใช้ passive เมื่อจำเป็นเท่านั้น**
  จำเป็นเมื่อไม่มีใครรู้ว่าใครกระทำ หรือผู้กระทำไม่สำคัญ นอกนั้นพูดตรง
- **คำแสดงความไม่แน่ใจใช้ได้คำเดียว ห้ามซ้อนกัน**
  อาจจะ, น่าจะ, ค่อนข้าง, โดยทั่วไปแล้ว ซ้อนกันแล้วประโยคไม่ได้บอกอะไร
  ❌ ตรงนี้อาจจะน่าจะทำให้ query ช้าลงได้ในบางกรณี
  ✅ query ตรงนี้ช้าลงตอน collection เกินหนึ่งล้าน row
- **ห้ามคำการตลาด พูดว่าสิ่งนั้นทำอะไร**
  ไร้รอยต่อ, ทรงพลัง, ครบวงจร, ล้ำสมัย, seamless, robust, powerful
  ❌ cache ตัวนี้ทรงพลัง และต่อกับ stack เดิมได้อย่างไร้รอยต่อ
  ✅ cache ตัวนี้อ่าน config เดิมของ Redis ได้ ไม่ต้องแก้ code ที่เรียกมัน
- **ห้ามทับศัพท์เป็นอักษรไทย** เขียน `deploy` ไม่ใช่ ดีพลอย
- **ชื่อที่ไม่ใช่คำธรรมดา ครั้งแรกที่พูดใส่คำอธิบายไทยในวงเล็บ**
  ✅ idempotent (เรียกซ้ำได้ผลเดิม)
  อธิบายในวงเล็บเดียวไม่ไหว ทิ้งชื่อแล้วอธิบายสิ่งนั้นแทน
- **หลายขั้นตอนเขียนเป็น flow หนึ่งขั้นตอนต่อบรรทัด**
  ✅ user กด Save → ระบบ validate ทุก field → ผ่าน
  บันทึกลง DB แล้วปิด modal→ ไม่ผ่าน field ที่ผิดขึ้นแดง

## ลิงก์

- **ทุก path เลขบรรทัด และ URL เป็นลิงก์ markdown ที่คลิกได้**
  path เทียบกับ root ของ workspace ผู้อ่านคลิกแล้วเปิดใน VSCode
  ✅ [.claude/rules/coding.md:8](.claude/rules/coding.md#L8)
  ✅ [.claude/settings.json](.claude/settings.json)
- **path ที่มีช่องว่างครอบด้วย `<>`** ไม่งั้น markdown ตัดลิงก์ตรงช่องว่าง
  ✅ [ep 12 final.mp4](<output/ep 12 final.mp4>)
- **ลิงก์โฟลเดอร์ใช้เมื่อหมายถึงโฟลเดอร์เท่านั้น**
  หมายถึงไฟล์ในโฟลเดอร์ให้ลิงก์ไปที่ไฟล์ คลิกโฟลเดอร์แล้วเปิด explorer
  ผู้อ่านต้องคลิกเพิ่มอีกที และเป็นคลิกที่ผิดทาง

## ตารางและภาพ

- **คอลัมน์ที่ต้องเทียบแถวเขียนใน code fence เว้นด้วยช่องว่าง**
  ชื่อกับความหมาย, status กับสิ่งที่อนุญาต, path กับชื่อหน้า: ทั้งหมดเข้า fence
  คอลัมน์ซ้ายเป็น identifier ภาษาอังกฤษ คอลัมน์ขวาเป็นภาษาไทย
  identifier เรียงแนวตรง ตาไล่ลงขอบเดียว
- **ตาราง pipe เฉพาะเมื่อผู้อ่านต้องเทียบตัวเลขตั้งแต่ 3 คอลัมน์ขึ้นไป**
- **ต้นไม้และ flow วาดเป็น ASCII ใน fence ห้าม mermaid**
  ไฟล์ต้องอ่านได้จาก source โดยไม่ต้องรออะไร render ก่อน

## ไฟล์ใต้ `.claude`

- **ทุกตัวอย่างในไฟล์สมมุติขึ้น และวางใน repo ไหนก็ได้**
  ชื่อไฟล์ โฟลเดอร์ ตัวแปร collection คำเฉพาะทาง: สมมุติขึ้นสด ๆ
  `src/api/user.ts`, `getUser`, `assets/images/` เดินทางได้ทุกที่
- **ห้ามเอ่ยชื่อโฟลเดอร์ script model collection หรือ env var จริงของโปรเจกต์**
  ผู้อ่านใน repo ถัดไปไม่มีสิ่งนั้น กฎที่ผู้อ่านตรวจไม่ได้คือกฎที่เขาเลิกเชื่อ
- **กฎที่จริงเฉพาะโปรเจกต์นี้เขียนใน `CLAUDE.md` ไม่ใช่ใน `.claude`**
  `.claude` เก็บวิธีทำงาน ซึ่งเหมือนกันทุกที่
  ข้อเท็จจริงของโปรเจกต์ โฟลเดอร์ stack เครื่องของมัน อยู่ในไฟล์ของโปรเจกต์เอง
